# 교대핏 (v2.5.7)

킹용코(@kingyongko) 교대근무 + 헬스 웹앱. **순수 HTML/CSS/JS**라서 이 폴더만 통째로 올리면 바로 돌아갑니다.

> ## 🔗 공개 주소
> **https://nyk5191-creator.github.io/kingyongko-shift/**
> 이 저장소 `main` 브랜치 루트가 GitHub Pages로 그대로 서빙됩니다(`.nojekyll` 포함, 빌드 없음).
> 아이폰 사파리는 **공유 → 홈 화면에 추가**, 갤럭시 크롬은 **⋮ → 홈 화면에 추가**로 앱처럼 설치합니다.

## 폴더 구성

```
kingyongko_shift_app/
├─ index.html              # 화면 (5탭: 달력 / 오늘 / 기록 / 가이드 / 설정)
├─ app.css                 # 테마 3종 (다크 골드 / 밝은 화이트 / 네이비 블루) · CSS 변수
├─ app.js                  # 교대 계산 · 내 회사 찾기 · 코칭 · 공휴일 · 기록 (localStorage)
├─ manifest.json           # PWA 매니페스트 (교대핏)
├─ sw.js                   # 서비스워커 — 네트워크 우선 + 오프라인 캐시 (캐시명 yongko-shift-v2.5.7)
├─ icon-192.png · icon-512.png          # 앱 아이콘 (다크 달력 + 골드 펄스)
├─ icon-maskable-192.png · ...-512.png  # 안드로이드 마스크용
├─ apple-touch-icon.png    # 아이폰 홈 화면 아이콘
└─ favicon-32.png
```

## v2.5.0에서 바뀐 것 (2026-11-27)

**가이드를 러닝·건강·계산기로 쪼개고, 내 숫자로 탄단지를 뽑는 계산기를 넣었습니다.**

- 가이드 칩이 6개로 — `전체 | 📕 전자책 핵심 | ❓ Q&A 백과 | 🏃 러닝 | 🩺 건강·수면 | 🧮 칼로리 계산기`.
- 기존 `🏃 러닝·건강`을 둘로 분리했습니다. `🏃 러닝` = 심박수 존(Zone 2/4) + 교대근무자 러닝 플랜. `🩺 건강·수면` = 3대 건강 수칙 · 수면·생체리듬 · 위장·혈당·피로 · **필수 영양제(마그네슘·비타민D) 신설**.
- **🧮 칼로리 계산기** — 성별(남/여) · 몸무게(기본 75kg) · 활동량(교대·현장직/일반 사무직) · 목표(다이어트 −400 / 유지 / 벌크업 +250)를 넣으면 `목표 하루 칼로리·단백질·지방·탄수화물`과 `닭가슴살 100g 약 N팩 + 햇반 210g 약 N공기` 환산 한 줄이 바로 나옵니다. 입력값은 `localStorage`(`state.calc`)에 저장돼 다시 열어도 그대로입니다.
- 계산식 — 유지칼로리 = 체중 × 33(남·현장)/30(남·사무·여·현장)/27(여·사무), 단백질 = 체중 × 2.0(감량)·1.8(유지·증량), 지방 = 체중 × 0.8, 탄수 = (목표 − 단백질×4 − 지방×9) ÷ 4. 탄수는 **50g 하한선**을 지키고, 그때는 칼로리가 그만큼 올라간다고 화면에 적어 줍니다.
- 저장값 호환 — 기존 `guideCat`이 `run`이면 그대로 `🏃 러닝`, `timeline`은 `all`로 폴백. `state.calc`가 없는 기기는 남·75kg·교대현장·유지로 시작.

- **오늘 탭 간소화** — 큰 코칭 카드 3장을 **1줄 요약 카드**(예: `🏋️ 기상 후 60분 운동 · 🍱 퇴근 후 단백질 30~40g · ☕ 새벽 2시 카페인 컷`)로 접고, `[자세히 ▾]`를 누를 때만 3단 상세가 펼쳐집니다.
- **'오늘 내 근무' 쉽게 고르기** — `3일차 오프` 같은 일차 번호 대신 `오늘 주간 (내일도 주간)` / `오늘 휴무 (내일도 휴무 · 다다음날 야간)`처럼 오늘·내일 흐름으로 고릅니다.
- **아이폰 상태바 겹침 수정** — `apple-mobile-web-app-status-bar-style`을 `black`으로.

## 기능

- **달력(첫 화면)** — 한 달 근무표 + 한 줄 오늘 바(오운완·식단 원탭). 상단 **`📷 이미지 저장`**(1080px PNG → 공유/다운로드), 날짜를 누르면 근무 변경 태그·일정·코칭·기록 수정. 하단에 이달 요약 + **이달 근태 정산**(대근·특근·연차·교육·예정 근무시간·월급 D-N).
- **오늘** — 오늘 근무(주/오후/야/휴) + 남은 근무시간, 운동·식단·카페인 코칭 3종, 오운완·식단 클린·러닝 km·한 줄 메모, 앞뒤 7일 전체 조 근무표.
- **기록** — 이달 누적 러닝, 오운완/식단 클린/출근일, 오운완 연속, 체중 추이, 날짜별 기록.
- **가이드** — 10초 사용법, 교대근무 백과, 가이드북·인스타 링크.
- **설정** — 화면 테마, **내 회사 찾기(업종 6종·43곳)**, 프리셋 6종(4조 2교대·3조 2교대·4조 3교대·2조 2교대·5조 3교대·주간연속 2교대) + 커스텀 주기(조 2~5개), 내 조, 조 순환 순서, '오늘 내 근무', 기준일, 근무 시간, **월급날**, JSON 백업, 초기화.

## 교대 계산 규칙

- 주기는 `주(주간) / 오(오후) / 야(야간) / 휴(휴무)` 문자열의 반복입니다.
- **기준일 = 내 조의 주기 1일째.** 조마다 `주기 길이 ÷ 조 수`일씩 밀립니다 (4조 2교대면 2일, 5조 3교대면 2일, 주간연속 2교대면 7일).
- 조 순서는 4조일 때 기본 `A→C→D→B`(킹용코 회사 기준), 그 외 조 수는 자연 순서(`A→B→C→D→E`)를 씁니다.
