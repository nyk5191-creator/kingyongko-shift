# 용코교대 (v2.0)

킹용코(@kingyongko) 교대근무 + 헬스 웹앱. **순수 HTML/CSS/JS**라서 이 폴더만 통째로 올리면 바로 돌아갑니다.

## 폴더 구성

```
kingyongko_shift_app/
├─ index.html              # 화면 (5탭: 오늘 / 달력 / 기록 / 가이드 / 설정)
├─ app.css                 # 다크 테마 (#0D0D0F / #17171B / #FFD400)
├─ app.js                  # 교대 계산 · 코칭 · 공휴일 · 기록 (localStorage)
├─ manifest.json           # PWA 매니페스트
├─ sw.js                   # 오프라인 캐시 (앱 껍데기, 캐시명 yongko-shift-v2.0.0)
├─ icon-192.png · icon-512.png          # 앱 아이콘
├─ icon-maskable-192.png · ...-512.png  # 안드로이드 마스크용
├─ apple-touch-icon.png    # 아이폰 홈 화면 아이콘
└─ favicon-32.png
```

## v2.0에서 추가된 것

- **가이드 탭** — ① 10초 사용 설명서(어르신·초보자용 큰 글씨 1-2-3 카드) ② 교대근무 백과 아코디언 8종(교대별 최적 분할 · 야간 퇴근 후 식사 · 야간 직후 vs 수면 후 운동 · 식단·카페인 4원칙 · 수면·생체리듬 · 위장·혈당·피로 · 영양제·수분 · 러닝·유산소) ③ 39p 가이드북·인스타그램 링크.
- **'오늘 내 근무' 원탭 세팅** — 오늘의 주기 위치(`1일차 주간` ~ `8일차 오프`) 버튼 하나만 누르면 기준일(anchorDate)을 역산해 저장. 첫 방문 시 세팅 시트가 자동으로 뜸. 기준일 직접 입력은 보조 옵션으로 유지.
- **공휴일** — 2026~2027 대한민국 법정공휴일(대체공휴일 포함 46일)을 내장. 달력은 공휴일 날짜를 빨간색 + 이름으로, 오늘 탭 날짜 헤더와 날짜 상세 시트에는 공휴일 배지로 표시. (임시공휴일은 미반영)
- **러닝 기록(km)** — 오늘 탭·날짜 상세 시트에서 러닝 거리 입력, 기록 카드에 `🏃 5.2km` 칩, 기록 탭 상단에 이달 누적 러닝, 달력에 주황 점.
- **달력 [내 달력 | 전체 조] 토글** — 전체 조는 월을 주 단위로 끊어 1조~N조 근무표를 나란히 비교(오늘 열 강조, 내 조 행 노란 배경).
- 서비스워커 캐시를 `yongko-shift-v2.0.0`으로 갱신. 기존 `localStorage` 데이터(`kingyongko_shift_v1`)는 그대로 이어받습니다.

## 로컬에서 열기

```bash
cd kingyongko_shift_app
python3 -m http.server 8123
# 브라우저에서 http://127.0.0.1:8123 접속 (폰에서는 같은 와이파이에서 PC IP 사용)
```

> `index.html`을 파일로 바로 열어도 화면은 뜨지만, 서비스 워커·홈 화면 추가는 `http(s)`에서만 동작합니다.

## 배포 (정적 호스팅)

- **GitHub Pages** — 이 폴더를 저장소 루트(또는 `docs/`)에 올리고 Settings → Pages에서 브랜치 선택.
- **Netlify / Vercel** — 폴더를 드래그해 배포. 빌드 명령 없음, 퍼블리시 디렉터리 = 이 폴더.
- 배포 후 아이폰 사파리에서 열고 **공유 → 홈 화면에 추가**하면 앱처럼 전체 화면으로 뜹니다.
- 서비스 워커 캐시를 갱신하려면 `sw.js`의 `CACHE` 값을 `yongko-shift-v2.0.1`처럼 올려 주세요.

## 기능

- **오늘** — 오늘 근무(주/오후/야/휴) + 남은 근무시간, 오늘 운동·식단 타이밍·카페인 컷오프 코칭 3종, 오운완·식단 클린 원탭 체크, 러닝 km, 한 줄 메모, 앞뒤 7일 전체 조 근무표.
- **달력** — 내 달력(날짜별 근무 배지 + 오운완·식단 클린·체중·러닝 점 + 공휴일) / 전체 조(주 단위 조별 근무표). 날짜를 누르면 그날 코칭·기록 수정.
- **기록** — 이달 누적 러닝, 이달 오운완/식단 클린/출근일, 오운완 연속 일수, 체중 추이 그래프, 날짜별 체중·러닝·운동 부위·메모 추가/삭제.
- **가이드** — 10초 사용법, 교대근무 백과, 가이드북·인스타 링크.
- **설정** — 4조 2교대(기본)·3조 2교대·4조 3교대·2조 2교대 프리셋 + 커스텀 주기 문자열, 내 조, '오늘 내 근무' 원탭 세팅, 기준일, 근무 시간, JSON 백업, 초기화.

## 교대 계산 규칙

- 주기는 `주(주간) / 오(오후) / 야(야간) / 휴(휴무)` 문자열의 반복입니다.
- **기준일 = 내 조의 주기 1일째.** 조마다 `주기 길이 ÷ 조 수`일씩 밀립니다 (4조 2교대면 2일).
- '오늘 내 근무'에서 `N일차`를 고르면 `anchor = 오늘 - ((N-1) - (조-1)×밀림일수) mod 주기길이`로 기준일을 역산합니다.
